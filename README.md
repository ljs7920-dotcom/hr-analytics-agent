# HR Analytics Agent — 이 순서 그대로만 따라하면 됩니다

개발을 전혀 모르셔도 괜찮습니다. 이 문서에 나온 순서대로, 화면에 보이는 버튼을 그대로 누르기만 하면 완성됩니다.
설치할 프로그램은 하나도 없습니다. 인터넷 브라우저(크롬, 엣지 등)만 있으면 됩니다.

**참고**: GitHub와 Vercel은 기본 화면이 영어로 되어 있어요. 그래서 이 문서에서는 **"영어 원래 이름 (한글 뜻)"** 형태로 같이 적어뒀습니다. 크롬 브라우저에서 자동 번역을 켜두면 한글로 보일 수도 있는데, 그럴 땐 괄호 안 한글 뜻을 참고해서 같은 버튼을 찾으시면 됩니다.

**미리 알아두면 좋은 것**: 이 작업은 총 3개의 사이트를 오가며 진행합니다.
1. 열쇠(키) 2개를 받는 곳 2군데 (한국어/영어 혼용)
2. 코드를 보관하는 곳 — GitHub (영어)
3. 코드를 실제 웹사이트로 바꿔주는 곳 — Vercel (영어)

전체 작업 시간은 처음 하시면 30분~1시간 정도 예상하시면 됩니다.

---

## 0단계. 압축 풀기

제가 드린 `hr-analytics-agent.zip` 파일을 다운로드 폴더에서 찾아서, **오른쪽 클릭 → "압축 풀기"(영어로는 Extract All)** 를 눌러주세요.
그러면 `hr-analytics-agent` 라는 폴더가 생깁니다. 어디 있는지 기억해두세요 (예: 바탕화면).

---

## 1단계. 열쇠(API 키) 2개 받기

### 1-1. 첫 번째 열쇠: OpenDART (기업 공시정보를 가져오는 곳)

이 사이트는 한국 사이트라 전부 한글입니다.

1. 브라우저 주소창에 정확히 이렇게 입력: `opendart.fss.or.kr`
2. 화면 오른쪽 위쪽 **"회원가입"** 클릭
3. 이메일 주소, 비밀번호, 이름 등을 입력하는 일반 가입 화면. 순서대로 채우고 가입 완료
4. 다시 **"로그인"**
5. 위쪽 메뉴 중 **"인증키 신청/관리"** 클릭
6. 페이지 안 **"인증키 신청"** 버튼(또는 탭) 클릭
7. 신청 사유는 "개인 학습/업무 활용" 정도로 적당히 적고 제출
8. 같은 메뉴 안 **"인증키 관리"** 탭에 가면 영어+숫자 문자열(예: `a1b2c3d4e5f6...`)이 보입니다. 이게 열쇠입니다.
9. 드래그해서 **복사(Ctrl+C)** → 메모장에 **붙여넣기(Ctrl+V)**

> 승인까지 몇 분~하루 정도 걸릴 수 있습니다.

### 1-2. 두 번째 열쇠: Gemini (AI가 데이터를 분석/설명해주는 곳, 무료)

이 사이트는 로그인은 한글로 보이지만, API 관련 화면은 영어로 나올 때가 많습니다.

1. 브라우저 주소창에 정확히 이렇게 입력: `aistudio.google.com`
2. 평소 쓰시는 **구글(Gmail) 계정으로 로그인**
3. 화면에 **"Get API key" (API 키 받기)** 버튼 클릭
4. **"Create API key" (API 키 만들기)** 버튼 클릭
5. "새 프로젝트를 만들까요?" 같은 질문이 나오면 기본값 그대로 두고 진행
6. 화면에 영어+숫자로 된 긴 문자열이 나타납니다. 복사해서 메모장에 붙여넣기

메모장에 이렇게 2줄이 있어야 합니다:
```
오픈다트 키: (1-1에서 복사한 값)
제미나이 키: (1-2에서 복사한 값)
```

## 2단계. GitHub — 코드를 보관하는 온라인 창고 만들기 (전체 화면 영어)

GitHub는 전체 메뉴가 영어입니다. 아래에 나오는 영어 이름 그대로 화면에서 찾으시면 되고, 옆에 한글 뜻을 같이 적어뒀습니다.

### 2-1. 가입하기

1. 브라우저에서 `github.com` 접속
2. 오른쪽 위 **"Sign up" (가입하기)** 버튼 클릭
3. 이메일 입력 → **"Continue" (계속)** → 비밀번호 만들기 → 사용자 이름(username, 영어 닉네임) 정하기
4. "로봇이 아닙니다" 확인 화면(퍼즐이나 체크박스)이 나오면 안내대로 클릭
5. 이메일로 온 인증코드를 화면에 입력
6. 완료되면 메인 화면(로그인 상태)으로 이동

### 2-2. 새 창고(저장소, Repository) 만들기

1. 오른쪽 위 **"+" (더하기 아이콘)** 클릭
2. 메뉴에서 **"New repository" (새 저장소)** 클릭
3. **"Repository name" (저장소 이름)** 칸에 `hr-analytics-agent` 입력
4. **"Public / Private" (공개/비공개)** 선택은 그대로 두세요 (기본값 Public이어도 괜찮음)
5. 맨 아래 초록색 **"Create repository" (저장소 만들기)** 버튼 클릭

### 2-3. 코드 파일 올리기 (Upload)

1. 생긴 페이지 안 파란 글씨 **"uploading an existing file" (기존 파일 업로드하기)** 링크 클릭
   - 안 보이면 위쪽 **"Add file" (파일 추가)** → **"Upload files" (파일 업로드)** 클릭
2. 0단계에서 압축 푼 `hr-analytics-agent` 폴더를 엽니다
3. 그 폴더 **안에 있는 것들(app 폴더, lib 폴더, package.json, README.md 등)을 전체 선택** (`Ctrl+A`, 맥은 `Cmd+A`)
   - 주의: 폴더 자체가 아니라 폴더 **안의 내용물**을 옮겨야 합니다
4. 선택한 파일들을 GitHub 브라우저 화면 가운데 점선 박스로 드래그 앤 드롭
5. 아래로 스크롤 → 초록색 **"Commit changes" (변경사항 저장하기)** 버튼 클릭

여기까지 하면 창고에 코드가 저장된 상태입니다.

## 3단계. Vercel — 실제로 접속 가능한 웹사이트 만들기 (전체 화면 영어)

### 3-1. 가입하기

1. 브라우저에서 `vercel.com` 접속
2. **"Sign Up" (가입하기)** 버튼 클릭
3. **"Continue with GitHub" (GitHub 계정으로 계속하기)** 클릭
4. GitHub 로그인 창이 뜨면 로그인 → **"Authorize" (권한 허용하기)** 클릭

### 3-2. 아까 만든 창고 불러오기 (Import)

1. Vercel 첫 화면에서 **"Add New..." (새로 추가하기)** 버튼 클릭 → **"Project" (프로젝트)** 클릭
2. GitHub 창고 목록에서 `hr-analytics-agent` 를 찾아 옆의 **"Import" (가져오기)** 버튼 클릭
   - 목록에 안 보이면 **"Adjust GitHub App Permissions" (GitHub 앱 권한 조정하기)** 링크 클릭해서 접근 범위 넓히기

### 3-3. 열쇠(키) 등록하기 — 가장 중요한 단계

1. 설정 화면을 아래로 내리면 **"Environment Variables" (환경 변수 = 프로그램이 쓸 비밀 열쇠를 넣어두는 곳)** 항목이 있습니다. 클릭해서 펼치기
2. 왼쪽 칸은 **"Key" (키 이름)**, 오른쪽 칸은 **"Value" (실제 값)** 입니다.
3. **첫 번째:**
   - Key 칸에: `OPENDART_API_KEY`
   - Value 칸에: 오픈다트 키 값 붙여넣기
   - **"Add" (추가)** 버튼 클릭
4. **두 번째:**
   - Key 칸에: `GEMINI_API_KEY`
   - Value 칸에: 제미나이 키 값 붙여넣기
   - **"Add" (추가)** 버튼 클릭
5. 두 개가 목록에 잘 추가됐는지 확인

### 3-4. 배포하기 (Deploy)

1. 화면 맨 아래 검은색 **"Deploy" (배포하기 = 실제로 웹사이트를 만들어서 인터넷에 올리는 작업)** 버튼 클릭
2. 1~2분 정도 기다립니다
3. **"Congratulations!" (축하합니다!)** 화면과 함께 미리보기가 뜨면 성공
4. 화면 위쪽 `https://hr-analytics-agent-xxxx.vercel.app` 같은 주소를 클릭 → 실제 사이트 열림

---

## 다 완성됐어요! 이제 이렇게 쓰시면 됩니다

1. 방금 열린 주소를 즐겨찾기에 추가
2. "기업명" 칸에 회사 이름(예: 삼성전자) 입력
3. "연도" 칸에 연도(예: 2024) 입력
4. "분석하기" 버튼 클릭 → 몇 초 기다리면 결과 표시

---

## 뭔가 안 될 때

| 증상 | 원인/해결 방법 |
|---|---|
| "분석하기"를 눌렀는데 빨간 글씨 에러 | 3-3단계 Key 이름(`OPENDART_API_KEY`, `GEMINI_API_KEY`)에 오타나 공백이 없는지 확인 |
| "요청이 너무 많다"는 에러 | Gemini 무료 사용량 순간 초과. 1분 후 재시도 |
| 특정 회사만 결과가 안 나옴 | 비상장이거나 해당 연도 보고서 미제출 가능성. 삼성전자 등 큰 상장사로 먼저 테스트 |
| 원인을 모르겠음 | Vercel 사이트 → 내 프로젝트 클릭 → **"Deployments" (배포 내역)** 탭 → 실패 표시(빨간색) 클릭하면 에러 로그가 보입니다. 캡처해서 보여주세요 |

막히는 부분이 있으면 어느 단계에서 멈췄는지, 화면에 뭐라고 나오는지 캡처해서 보내주세요.
